ترنج — نرم‌افزار حسابداری طلافروشی

ترنج یک برنامه‌ی ویندوزی برای حسابداریِ طلافروشی است (فاکتور، نسیه، قلک طلا، انبار، آمار). همه‌ی اطلاعات روی کامپیوترِ خودِ مغازه نگه‌داری می‌شود.

سیاست حریم خصوصی

استفاده از Google Drive: ترنج فقط برای پشتیبان‌گیری از اطلاعاتِ خودِ کاربر از Google Drive استفاده می‌کند، و فقط وقتی کاربر خودش در تنظیماتِ برنامه آن را وصل کند.

دسترسی محدود: برنامه فقط به فایل‌هایی دسترسی دارد که خودش در Drive ساخته است (دسترسیِ drive.file). به هیچ فایل یا پوشه‌ی دیگری در Drive دسترسی ندارد.

کجا ذخیره می‌شود: فایل‌های پشتیبان فقط در Google Driveِ خودِ کاربر و روی کامپیوترِ خودِ او ذخیره می‌شوند. هیچ اطلاعاتی به سرورِ ما یا هیچ شخص یا شرکتِ دیگری فرستاده نمی‌شود، فروخته نمی‌شود و برای تبلیغات استفاده نمی‌شود.

حذف و قطعِ دسترسی: کاربر هر وقت بخواهد می‌تواند فایل‌های پشتیبان را از Drive پاک کند، یا دسترسیِ برنامه را از آدرسِ myaccount.google.com/permissions بردارد.

Toranj — Gold Shop Accounting Software

Toranj is a Windows desktop application for gold shop accounting (invoices, credit sales, gold savings, inventory, statistics). All data is stored locally on the shop's own computer.

Privacy Policy

Use of Google Drive: Toranj uses Google Drive only to back up the user's own data, and only after the user connects it in the application's settings.

Limited access: The application requests the drive.file scope, so it can only access files that it created itself. It cannot see or access any other files or folders in the user's Drive.

Where data is stored: Backup files are stored only in the user's own Google Drive and on the user's own computer. No data is sent to our servers or to any third party, it is never sold, and it is never used for advertising.

Google API Services: Toranj's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion and revoking access: Users can delete the backup files from their Drive at any time, or revoke the application's access at myaccount.google.com/permissions.
